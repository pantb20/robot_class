# 💡 LED 长条灯智能识别与巡检实训项目 2026年11月2日

## 🎯 项目背景
本项目面向中小学信息科技/人工智能课程及机器人视觉方向实训。通过“教室/机房吊顶长条平板 LED 灯”的开灯（`on`）与关灯（`off`）状态识别，帮助学生由浅入深地理解计算机视觉的核心原理与工程落地。

## 📂 核心内容与目录结构
本仓库采用“由浅入深、循序渐进”的三步法教学设计：

1. **阶段一 (`level1_global_brightness.py`)**：全局平均亮度判定法（初识图像灰度与像素统计）。
2. **阶段二 (`level2_roi_detection.py`)**：固定 ROI 区域与 HSV 明度分析（理解局部裁剪与抗环境干扰）。
3. **阶段三 (`level3_contour_detection.py`)**：高光二值化、轮廓自动查找与可视化监控（掌握阈值分割与轮廓检测）。
4. **进阶拓展（可选）**：结合 YOLO 目标检测与批量巡检报表导出。
